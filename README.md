# Local Notes and Todos

A pure client-side notes and todo page built with vanilla JavaScript. Open `index.html` in a browser. Notes and todos are stored only in that browser's `localStorage`.

There is no backend, API, database, authentication, server-side runtime, container, build step, workflow, or automated deployment. Hosting these static files cannot sync notes or todos between browsers or devices: each browser keeps its own independent data. Clearing browser storage deletes its data.

This public disposable repository is used by its owner for a real PR840 unsupported-static-app classification acceptance test. It is not a hosted multi-user service. No generated deployment files or workflows are included.
